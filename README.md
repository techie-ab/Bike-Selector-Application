# Bike-Selector-Application

## Overview

Bike-Selector-Application is a simple command-line program written in C that helps users choose their preferred bike model based on brand and specifications. The program offers an interactive menu allowing users to select between different bike brands and models, displaying relevant information such as price and mileage.

## Features

- Select from two major bike brands: TVS and Bajaj
- Choose between different models for each brand
- Display bike price and mileage information
- Option to make multiple selections in a single session

## How to Use

1. Clone this repository to your local machine.
    ```bash
    git clone https://github.com/techie-ab/Bike-Selector-Application.git
    ```
2. Navigate to the project directory.
    ```bash
    cd Bike-Selector-Application
    ```
3. Compile the program.
    ```bash
    gcc -o bikeselector bikeselector.c
    ```
4. Run the program.
    ```bash
    ./bikeselector
    ```
